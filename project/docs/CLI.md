# CLI and document artifacts

`vellric --help` and each subcommand's `--help` define available options. `inspect`, `convert` and `render` process one local regular file, regardless of extension, or bounded stdin (`-`). Input symlinks and non-regular files are refused. The input is copied and hashed into private storage; no original file is rewritten. Passwords come only from `--password-file` or `--password-stdin`, never command-line values or manifest fields.

`--out` must not exist. A private staging directory beside it is populated, validated and published through macOS `renameatx_np(RENAME_EXCL)` or Linux `renameat2(RENAME_NOREPLACE)`. Unsupported platforms refuse. Concurrent destination creation never causes replacement. This provides atomic visibility, not a promise of durable recovery after power loss; no fsync durability guarantee is made. Supervised failure/cancellation removes staging and temporary work; a killed supervisor can leave hidden private directories, which must not be consumed as completed results.

## Commands

`inspect` fully traverses every page and emits exact native texts, dimensions, raster coverage and OCR selection. `--layout` adds character/font/quad geometry, links, image placements, interpreted runs and best-effort tables/CSV. Table failure records a warning and never removes native text.

`convert` defaults to `--ocr auto --preflight on --dpi 300 --jobs 1 --language eng`. OCR candidates have empty native text or summed clipped raster-image area at least half page area. Coverage is a sum, not union, and can exceed one. The preserved Drawbridge v1 arithmetic intersects unrotated image bboxes with the displayed (intrinsically rotated) page rectangle; those frames can differ on non-square rotated pages. This historical selection behavior is deliberately unchanged and named explicitly in `coverage_formula`. OCRmyPDF's disposable derivative is count checked; recognized text comes from Tesseract over original visible pixels at four rotations. The first-strip winner determines later quiet-row strips. `--structure native` adds separately gated Markdown; exact text artifacts are untouched. `--diagnostics` retains Tesseract TSV, which contains document text and must be protected like the source.

`--ocr-pages RANGE` explicitly selects recognition pages within a complete document conversion and requires `--ocr auto`. Unselected native pages stay exact; unrecognized candidates remain declared. `--rotate-threshold` controls OCRmyPDF orientation confidence (finite, nonnegative; default 2), and `--preflight-timeout-seconds` sets its bounded deadline (default 1800). Password and zero-page refusals include partial inspection facts in terminal `details.inspection`, while publishing no bundle.

`--ocr never` produces a complete native-only bundle and explicitly reports outstanding candidate numbers. A caller requiring OCR must reject these bundles. `--searchable-pdf` requires OCR auto/always and preflight on. With no selected candidates it produces a byte-identical snapshot copy marked `native-copy`; otherwise it retains the count-checked derivative, marked `ocr-preflight`, with a signature warning.

`render` supports PNG, PNM and JPEG, one-based validated `--pages` ranges, 300 DPI, rotation 0/90/180/270, grayscale/RGB, JPEG quality and arbitrary displayed-page `--clip x0,y0,x1,y1`. Complete inspection precedes the requested subset. `--strips` uses bounded quiet-row clips; `--max-side` explicitly permits reduced DPI. Strip mode applies the proven 30000-pixel width cap; effective DPI is recorded. A side above 30000 pixels refuses before raster allocation unless strips or an explicit max-side reduction applies. `--clip` must fit every selected page. A raster exceeding the byte budget refuses before allocation instead of silently reducing DPI under that budget.

`doctor` prints a concise summary; `doctor --json` reports software/schema/behavior, installed engines, executable hashes, language-data hashes and actual enforcement. It does not install, fetch or process a document. Full-OCR qualification currently requires PyMuPDF 1.28.2, Tesseract 5.5.2 and OCRmyPDF 17.7.0. Other engine versions are not silently accepted. `--tessdata-dir DIR` explicitly sets the qualified engines' data directory without inheriting ambient credential or loader settings. `doctor --language eng+deu --tessdata-dir DIR` and jobs hash only the requested language packs (plus `osd` when preflight rotates), using the directory reported by the actual Tesseract executable or the explicit directory. Adding an unrelated language pack does not change processing identity.

## Schema v1

`manifest.json` uses `vellric.document/1.0`, independently versioned from software and behavior `drawbridge-0.4.3-pymupdf-1.28.2/v1`. See the [machine-readable schema](document.schema.json). Per-page files are authoritative boundaries; `document.txt` is form-feed joined, and a literal form-feed inside a page is not a separate page. Exact `native.txt` and `text.txt` preserve whitespace, ligatures and empty strings. `document.md` trims page presentation, removes NULs and uses the established explicit empty-page marker. `structured.md` is optional and never substitutes for fidelity evidence.

The manifest records input SHA-256/size, page order/count, inspection, methods, selection/coverage formula, recognition completeness, formatting eligibility/fallback, render settings, engine/data facts, processing fingerprint, elapsed times and watchdog samples. File entries name relative paths, byte sizes, SHA-256 and media types. Empty page files exist. Text is UTF-8; reader Markdown uses LF. CSV uses RFC 4180 via Python's CSV writer. JSON contains finite numbers. Public manifests exclude original paths/passwords/env; URI and PDF text inside artifacts remain potentially private document data.

`layout.json` names its unrotated cropped-page coordinate frame. Native raw font sizes/flags are retained; interpreted formatting rounds to half-points. Page geometry records MediaBox, CropBox, intrinsic rotation and affine matrices. The PDF-to-unrotated matrix is captured with intrinsic rotation disabled in memory so cropped rotated pages retain their PDF-space offsets. CLI crop coordinates use the displayed page: top-left origin, x right/y down, intrinsic rotation already applied. Additional output rotation follows clipping. `displayed_to_pdf` maps to original PDF user space; render `displayed_to_pixels` includes DPI/rotation, and `pixel_origin` gives the pixmap's translated origin. Subtract that origin for image-local pixels. Render rectangle rounding follows MuPDF, not an invented integer crop convention.

## Failures and supervision

`--status-json` reserves stdout for one `vellric.status/1.0` terminal record. Progress is stderr (human or NDJSON with `--progress json`; disabled with `none`). Native/external diagnostics cannot contaminate stdout. Exit 0 means validated complete publication; 2 usage; 3 blocked password/zero pages; 4 malformed/non-PDF/open/read/hash failures; 5 dependency/OCR/count/resource/deadline/artifact/internal failures. An existing destination remains an `artifact-invalid` execution failure (exit 5). Usage errors have terminal status `failed`, code `usage` and exit 2. Codes are stable machine-readable classifications; retry advice never recommends blindly retrying identical input. A killed CLI may produce no record: callers must treat missing status as failure.

Defaults: input 512 MiB, output 2 GiB, pages 10000, job 3600 seconds, each recognition call 300 seconds, preflight at most 1800 seconds, process-group RSS watchdog 2048 MiB, raster admission 256 MiB, preview at most 40 million gray pixels. `--jobs` bounds OCR page engines/preflight jobs; `OMP_THREAD_LIMIT=1`. Cross-document aggregate admission belongs to the caller. Worker and descendants share a private job process group, terminated on supervised exit.

RSS/progress/deadline supervision runs roughly every 100 ms; private disk sampling runs roughly once per second. These watchdogs can overshoot; sampled peaks can miss transients. Raster admission is an estimate before native allocation, not a guarantee against decompression bombs. The process boundary is not a network/filesystem sandbox. Credentials, loader/Python injection settings and user plugin settings are omitted from child environments; explicit tessdata directory is allowlisted; trusted standard executable search paths are used with argument arrays and no shell. Embedded actions/URLs/attachments are never executed or fetched. For genuinely hostile PDFs, deploy the tool inside a separately reviewed offline container/sandbox with hard host limits. No network-service safety claim is made.

Native formatting eligibility is independent of whether structure was requested; `structure_requested` distinguishes the request. OCR records always include `bands`. The processing fingerprint uses actual engine/executable and requested language-data identities plus processing settings, excluding platform/license prose and document-dependent candidate selection. Linux RSS supervision reads procfs; macOS requires `/bin/ps`. `doctor` reports supervision/publication availability. On the first OCR page fault, no further pages are submitted and active recognition calls are cancelled.


## Canonical native identities and PDF ranges

`render --subset-pdf --pages START-END` also produces subset.pdf and pdf_subset manifest metadata naming the original selected pages. A contiguous range uses one native insertion and no new trailer ID, producing deterministic bytes for the qualified engine. Engine upgrades can change PDF producer metadata and therefore derivative byte hashes; retain existing derived files when upgrading a consumer. Noncontiguous selections retain source page order. Every artifact has its independent size/digest entry.

`render --pixel-fingerprints --dpi 144` requires full RGB pages with no extra rotation, clip, strips or max-side scaling. Each render records pixel_sha256, difference_hash, dimensions, channels and algorithm mupdf-rgb-dhash-9x8/v1. Form appearances and annotations are included. The source's intrinsic rotation is preserved. Fingerprint raster admission also covers the grayscale buffer.

`image INPUT --out OUTPUT` publishes a complete canonical native image job, with no OCR. Optional --width WIDTH --height HEIGHT downsizes to those explicit dimensions and never upsamples. Pillow reads the header for raster admission before native decoding. The normalized RGB PNG and source-bound fingerprint/dimensions are declared artifacts; native alpha/colorspace/resampling semantics are preserved for compatibility. This is a first-image-frame identity operation, not a multi-frame text conversion. The method label is native-image and geometry units are pixels. Both dimensions must be positive and at most 30000. Source symlinks, oversize rasters and incomplete outputs are refused under normal supervision.

Image jobs use the same dependency-unavailable and resource-limit exit class 5 as PDF jobs. image-invalid and image-operational also use class 5: invalid decoded image dimensions and other image decoding/filesystem failures, respectively. Page fingerprints require lossless PNG or PNM output. Pixel hashes read the native sample memory view incrementally, without allocating full raster copies.

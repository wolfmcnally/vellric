# Release documentation audit

Both first public candidates are 0.1.0. The capability introductions link working installation, CLI/API/configuration, platform prerequisites, examples, troubleshooting and licensing guides. Vellric is independently installed; Drawbridge never imports its engine. Paid provider stages are explicitly optional and require profiles and credentials.

Six core README/CLI/API flows were executed from downloaded release wheels in fresh directories, without sibling checkout imports. They cover native inspection, conversion and rendering, local text conversion, PDF conversion/verification and the installed Drawbridge API. Exact synthetic native text is asserted. Final-commit package repetitions and OCR examples are owned by the ignored release-receipt.json and documentation-examples.json, rather than predicted here. All relative links in both READMEs and these guides resolve.

The optional audio installation uses the exact publicly reachable Quillric source commit c48b76e522f4e677df9184a2e82469ddcdb9cee9. A fresh install of that source followed by the Drawbridge audio extra passed CLI startup and transcribe/drawbridge imports. Quillric 0.1.0 returned 404 on public PyPI at preparation; the guide therefore gives the verified Git route. No paid transcription, cleanup or model request was made.

The retained transcribe import, CLI and artifact directory names are compatibility interfaces, not an instruction to install the old distribution. The inherited drawbridge-0.4.3-pymupdf-1.28.2/v1 behavior identifier identifies processing semantics, not either package version. Private development history is excluded from this public repository. User guides carry no operator-local paths or private client references; illustrative absolute paths are explicitly placeholders. Original fixtures, word gates, proof records, methodology and license provenance are preserved.

Publication and live consumer changes remain separate authorized transitions. There is no blanket human readability gate for unchanged, parity-proven text; the viewer records actual metadata differences and supports optional inspection.
